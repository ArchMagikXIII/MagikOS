# Prompt

Magikos keeps the stock bash prompt. If you want something with more information or style, a cross-shell prompt like [Starship](https://starship.rs/) is an easy upgrade: install it, then add `eval "$(starship init bash)"` to your `~/.bashrc` and configure away in `~/.config/starship.toml`. There's a lot you can do. Just don't go overboard (or do go overboard, do whatever you want, it's your computer!)
